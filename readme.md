This Repo contains my personal "Mini Projects" that I develop to improve my coding capabilities.

This Repo currently contains the following Mini Projects:

| **gFetch** | A copy of neofetch or fastfetch that retrieves Hardware information from the host.  It only supports ElementaryOS (and therefore any other ubuntu based distro). The whole thing is written in Golang to improve my Go skills.|
|------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|     **localTransfer**       | A simple CLI tool that enables the user to transfer text from one device trough another by an exposed webservice that closes automatically after the content was copied.                                                                                                                                                         |
|     **golangAsciiGraphics**       | A simple Ascii Graphics renderer that renders Ascii Graphics basend on the provided data.                                                                                                                                                         |
